# קמה בקול

מקור דשבורד הבוקר של מועדון אמא מגשימה, קרן בן עמי.

הפעלה ציבורית: https://kama-bakol-morning-room.immamagshima.workers.dev

היישום הדינמי פועל ב־Cloudflare Worker עם D1. GitHub הוא ארכיון המקור, ואינו מחליף את השרת. קובצי המדיה המאושרים מתארחים בדשבורד ומפורטים ב־assets-manifest.json. המפתח הפרטי ונתוני המשתתפות אינם נשמרים במאגר. לשחזור בנייה יש להחזיר נכסי assets מהגיבוי המקומי או מכתובות הנכסים שבמניפסט, ואז npm run build.

בדיקות וגבולות האימות: qa/RELEASE-QA-2026-11-01.md.
